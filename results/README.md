# Results directory

Analysis scripts create outputs here. Only `release_tables/` is versioned because it contains compact final tables supporting the manuscript results; other generated files are ignored and can be recreated from public inputs.

The BMC revision release tables include the four-module ZG/intermediate-versus-ZF/ZR axis, patient-paired GSE274314 location and CYP11B2-removal sensitivity results, 3×3/4×4/5×5 grid occupancy and regional-dispersion sensitivity, and external GSE60042/GSE156931 outputs.
